## Run Notes

The metric diagrams were computed directly from the original 72-row ablation CSV.
The original fitted fields/final renders were not persisted, so the visual grids
were generated by rerunning the same 72 exact-CUDA cells: four images, three
budgets, six variants, seed 0, max-side 768, 1500 iterations.

The rerun completed 72/72 cells with zero errors in 33.07 minutes. It wrote four
target images, 72 reconstructions, four by-image grids, three by-budget grids,
and `index.html`.

Mean rerun PSNR delta versus the original CSV was -0.0701 dB at 2000 Gaussians,
+0.1579 dB at 5000 Gaussians, and +0.0103 dB at 10000 Gaussians. Grid labels
use the original CSV metrics; `visual_metrics.csv` records both CSV and rerun
metrics for audit.
